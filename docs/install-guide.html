Время

~15 мин

ОС

Версия

0

Перед началом

Проверьте, что это у вас уже есть — остальное поставим по ходу
  • Windows-компьютер с правами администратора (для установки Python)
  • Установленный и лицензированный nanoCAD x64 26.0 (если ещё нет — ставится отдельно с сайта Nanosoft, это вне рамок этой инструкции)
  • Доступ к вашему аккаунту GitHub (LectorNZ) — репозиторий приватный, для скачивания нужно быть авторизованным
1

Установите Python

Он нужен, чтобы запускать сам мост-сервер
  1. 1

    Откройте PowerShell

    Пуск → напишите PowerShell → Enter.

  2. 2

    Установите Python 3.12

    Вставьте команду и нажмите Enter, дождитесь надписи «Successfully installed»:

    winget install --id Python.Python.3.12 -e --source winget

    Нет winget (старая Windows)? Скачайте установщик на python.org/downloads и при установке обязательно поставьте галочку «Add python.exe to PATH».

  3. 3

    Проверьте

    Закройте и заново откройте PowerShell (чтобы обновился PATH), затем:

    python --version

    Должно показать что-то вроде Python 3.12.10.

2

Поставьте два пакета

Связь с nanoCAD (pywin32) и протокол для Claude (mcp)
python -m pip install pywin32 "mcp[cli]"

Займёт минуту-две, в конце должно быть без красных ошибок.

3

Скачайте проект с GitHub

Готовый код моста — ничего писать не нужно
  1. 1

    Откройте репозиторий в браузере

    Зайдите под своим GitHub-аккаунтом и откройте github.com/LectorNZ/nanocad-mcp-server.

  2. 2

    Скачайте архив

    Зелёная кнопка Code → Download ZIP.

  3. 3

    Распакуйте в постоянное место

    Не в Загрузки и не во временную папку — например:

    C:\Users\<ваше_имя>\nanocad-mcp-server

    Дальше эта папка и есть «корень репозитория» — на неё будем ссылаться.

4

Подставьте свои пути

Единственный шаг, где нужно кое-что подправить руками
  1. 1

    Узнайте, где лежит python.exe

    (Get-Command python).Source

    Скопируйте результат — что-то вроде C:\Users\...\AppData\Local\Programs\Python\Python312\python.exe.

  2. 2

    Откройте файл .mcp.json

    Путь внутри скачанной папки:

    nanocad-mcp-server\plugins\nanocad-ai\.mcp.json

    Откройте в Блокноте и замените оба пути (command и args) на пути именно этого компьютера — python.exe из прошлого шага и server\nanocad_server.py внутри вашей скачанной папки:

    {
  "mcpServers": {
    "nanocad-application-server": {
      "command": "C:\\путь\\к\\python.exe",
      "args": ["C:\\путь\\к\\nanocad-mcp-server\\plugins\\nanocad-ai\\server\\nanocad_server.py"]
    }
  }
}

    Важно: в JSON каждый обратный слэш нужно писать двойным — \\, а не \.

5

Подключите плагин к Claude Code

Один файл настроек, два новых ключа
  1. 1

    Откройте файл настроек

    %USERPROFILE%\.claude\settings.json

    Нет файла или он пустой? Создайте с содержимым {} и продолжайте.

  2. 2

    Добавьте два ключа

    Впишите (или аккуратно объедините с уже существующим содержимым, если там что-то есть — ничего чужого не удаляйте):

    {
  "extraKnownMarketplaces": {
    "nanocad-ai": {
      "source": { "source": "directory", "path": "C:\\путь\\к\\nanocad-mcp-server" }
    }
  },
  "enabledPlugins": {
    "nanocad-ai@nanocad-ai": true
  }
}

    path — это путь к папке, куда вы распаковали архив на шаге 3 (та, что содержит .claude-plugin).

6

Перезапустите и проверьте

  1. 1

    Полностью закройте и заново откройте Claude Code

    MCP-серверы подключаются только при старте сессии.

  2. 2

    Откройте nanoCAD x64 26.0

    С любым документом — сервер подключается к уже запущенному приложению.

  3. 3

    Спросите Claude что-нибудь простое

    Например «нарисуй в nanoCAD окружность радиусом 10» — если он это делает, всё подключено верно.

✓ Готово

С этого момента Claude работает с nanoCAD на этой машине так же, как на исходной. Повседневные команды, автозагрузку в nanoCAD и разбор возможных зависаний смотрите в основной инструкции — ссылка ниже.

⚠ Если Claude не видит инструменты nanoCAD после перезапуска

Проверьте по порядку: 1) файл settings.json — валидный ли JSON (лишняя запятая — частая причина); 2) путь в path действительно ведёт на папку с .claude-plugin внутри; 3) в .mcp.json путь к python.exe существует и без опечаток.
