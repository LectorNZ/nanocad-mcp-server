Инструкция по эксплуатации

Мост Claude ↔ nanoCAD

Как подключиться и работать с чертежами в nanoCAD через Claude Code

Плагин

nanocad-ai

Цель

nanoCAD x64 26.0

Канал связи

COM / ActiveX

Версия

1.0

01

Как это устроено

Локальный MCP-сервер на Python (nanocad_server.py) подключается к уже запущенному nanoCAD 26 через его COM-интерфейс автоматизации — тот же принцип, что использует AutoCAD ActiveX. Claude Code видит этот сервер как плагин и получает инструменты для работы с чертежом: команды, LISP-скрипты, размеры, чтение сущностей, сохранение файла.

Настройка уже выполнена и проверена на реальном чертеже — дальше только то, что нужно знать вам как пользователю.

02

Ежедневный сценарий

  1. 1

    Откройте nanoCAD x64 26.0

    С нужным документом — сервер подключается только к уже запущенному экземпляру, сам он nanoCAD не запускает.

  2. 2

    Проверьте, что Claude Code видит плагин

    Инструменты nanocad-ai подхватываются один раз за сессию — после установки или обновления плагина перезапустите сессию Claude Code.

  3. 3

    Работайте с чертежом как обычно

    Просите Claude нарисовать, проставить размеры, прочитать сущности или сохранить файл — он использует те же инструменты, что и напрямую с nanoCAD.

03

Быстрые команды прямо в nanoCAD

В репозитории лежит небольшой LISP-файл с двумя командами для проверки моста без участия Claude — удобно, когда нужно быстро посмотреть статус самому.

(load "C:/Users/zemlyanskiy/.claude/local-plugins/nanocad-ai/plugins/nanocad-ai/nanocad/claude_bridge_commands.lsp")

CLAUDESTATUS

Печатает в командную строку версию nanoCAD, имя документа и краткую памятку про перезапуск сессии.

CLAUDEHELP

Показывает те же три шага сценария выше в диалоговом окне — на случай, если инструкция не под рукой.

04

Сделать команды доступными всегда

Чтобы не грузить файл вручную каждый раз, добавьте его в «Startup Suite» — стандартный, штатный способ автозагрузки LISP в nanoCAD:

  1. 1

    Командная строка nanoCAD → введите APPLOAD (или Сервис → Загрузка приложений).

  2. 2

    Найдите файл claude_bridge_commands.lsp по пути выше и нажмите «Загрузить».

  3. 3

    Откройте вкладку «Startup Suite» → «Добавить» → выберите тот же файл → «Закрыть». С этого момента команды будут грузиться автоматически при каждом запуске nanoCAD.

05

Кнопка на панели — по желанию

Если хочется не набирать команду руками: Сервис → Настройка интерфейса (CUI) → создайте кнопку, укажите в поле «Макрос» строку ^C^C_CLAUDESTATUS и перетащите её на любую панель. Это стандартный для nanoCAD/AutoCAD способ, здесь автоматически ничего не настраивалось.

⚠ Если nanoCAD «завис» посреди работы Claude

Команды с выбором объекта по точке (DIMDIAMETER, DIMRADIUS — их Claude использует редко, предпочитая прямые COM-методы) иногда открывают диалог Object selection, если точка попадает сразу на две сущности. Диалог блокирует всю связь — Claude не видит ошибки, команды просто перестают что-либо делать. Посмотрите на окно nanoCAD и закройте диалог — после этого всё продолжит работать.
